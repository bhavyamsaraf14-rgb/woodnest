
# WoodNest - Furniture Shopping Website

WoodNest is a modern and responsive furniture shopping website designed to showcase stylish and affordable furniture for homes.

## Live Website

**Website:** https://woodnest-eight.vercel.app/

**GitHub Repository:** https://github.com/bhavyamsaraf14-rgb/woodnest

## Features

- Modern and responsive user interface
- Home page with furniture collections
- Product listings with images and prices
- Product details and descriptions
- About Us page
- Contact form
- Easy navigation
- Mobile-friendly design

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- TanStack Start
- Vite
- Git and GitHub
- Vercel

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/bhavyamsaraf14-rgb/woodnest.git
```

### 2. Navigate to the project folder

```bash
cd woodnest/woodnest
```

### 3. Install dependencies

Requires Node.js 22.12.0 or later.

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

Open the local URL displayed in the terminal.

## GitHub Setup

1. Created a public GitHub repository named `woodnest`.
2. Uploaded the website source code.
3. Added the required project files and dependencies configuration.
4. Committed the files to the `main` branch.

GitHub stores the website source code and tracks changes made to the project.

## Deployment Using Vercel

1. Signed in to Vercel using GitHub.
2. Selected the `woodnest` repository.
3. Imported the repository into Vercel.
4. Selected **TanStack Start** as the application preset.
5. Set the root directory to `woodnest`.
6. Clicked **Deploy**.
7. Vercel successfully built and published the website.

## Automatic Deployment

Vercel is connected to the GitHub repository.

Whenever new code is pushed to the connected `main` branch:

1. Vercel detects the new commit.
2. It downloads the updated source code.
3. It installs the necessary dependencies.
4. It builds the website.
5. It publishes the updated version automatically if the build succeeds.

This process is called **Continuous Deployment**.

## How Vercel Builds and Publishes the Website

Vercel automatically handles the deployment process:

- **Source Code:** Fetches the project from GitHub.
- **Dependencies:** Installs the required packages.
- **Build:** Compiles the application for production.
- **Hosting:** Makes the website accessible online.
- **HTTPS:** Provides a secure connection.
- **Updates:** Automatically redeploys after new commits.

## Domain and Hosting

The website is hosted using Vercel's free `.vercel.app` subdomain.

**Live URL:** https://woodnest-eight.vercel.app/

A custom domain can also be connected through:

**Vercel Dashboard → Project → Settings → Domains**

After adding a custom domain, the required DNS records must be configured with the domain provider.

## Conclusion

WoodNest demonstrates the complete process of developing, managing, and deploying a website using GitHub and Vercel.

The project shows how GitHub provides source code management while Vercel enables automated builds, hosting, and continuous deployment.
